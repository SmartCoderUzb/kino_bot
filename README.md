# 🎬 Kino Bot — Telegram Movie Streaming & Download Platform

Kinolarni kod orqali yuklash, qidirish va boshqarish tizimi.

## ✨ Imkoniyatlar
- Kinolarni kod orqali yuklash va seriallar bo'limi
- Majburiy obuna (Ommaviy va Zayavka kanallar)
- Premium obuna tizimi va to'lovlar
- Ommaviy xabar tarqatish (Broadcast)
- To'liq admin panel va statistika
- PostgreSQL (schema isolation) va Redis

## 🚀 O'rnatish
```bash
python3 -m venv env
source env/bin/activate
pip install -r requirements.txt
cp .env.example .env
python main.py
```
